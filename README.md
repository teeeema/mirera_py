Влияние приложения для медитации на время засыпания

В этом проекте я сравниваю, сколько времени требовалось одним и тем же участникам, чтобы заснуть до начала использования приложения для медитации и через четыре недели. Учебные данные генерируются в ноутбуке. Из 50 участников в парный анализ вошли 44 с валидными измерениями до и после.

## Как запустить проект

Для проверки воспроизводимости использовался Python 3.15.2.

1. Откройте папку проекта в VS Code. Установите расширения **Python** и **Jupyter** от Microsoft, если их ещё нет.
2. Откройте встроенный терминал PowerShell и выполните следующие команды.

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

3. Откройте `project_sleep.ipynb`. В правом верхнем углу нажмите **Select Kernel** и в разделе **Python Environments** выберите окружение `.venv`.
4. Нажмите `Ctrl+Shift+P` и выберите **Jupyter: Restart Kernel and Run All Cells**. Ядро перезапустится, и все ячейки выполнятся по порядку.

## Результат

В учебных данных среднее время засыпания сократилось на 3,11 минуты. 95%-й доверительный интервал для среднего сокращения составил от 1,84 до 4,39 минуты. Чтобы оценить вклад самого приложения, нужно провести исследование с группой сравнения.
